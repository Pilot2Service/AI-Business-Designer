# Maturity Levels

This is an internal tracking convention, not a public completeness rating.
It lives in `skills_index.json` (not the SKILL.md frontmatter — see
`frontmatter_schema.md`) and exists so the owner has a private backlog of
where to keep adding real-world depth. It is not surfaced in a skill's own
documentation, and an agent should not recite it to the person it's
helping — see `AGENT_GUIDE.md` section 3-4. Every skill, at every level
below, is real, grounded, usable methodology — the level only tracks how
much of the owner's own field experience has been layered on top.

| Level | Meaning | Who can set it |
|---|---|---|
| `scaffold` | Structure and anchoring are in place; own experience not yet added | Default for a new skill |
| `draft` | Refinement notes filled in, used once in practice, not yet validated more broadly | Owner |
| `validated` | Used in several real situations, proven to work | Owner |
| `canonical` | Established, elevated to the organization's official standard technique | Owner |
