# Tool category map — AI-native stack

Snapshot from **June 2026** (`workshop-source.md`, `tools.md`). Categories
are more durable than product names — always check a tool's current
status before committing. Used in the `ai-native-tool-stack-selection`
skill.

| # | Category | Purpose | Examples (June 2026 — check currency) |
|---|---|---|---|
| 1 | AI thinking partner | General planning, writing, reasoning; business context persists in a project | Claude, ChatGPT, Gemini |
| 2 | Research and information retrieval | Sourced information retrieval, deep research from your own documents | Perplexity, NotebookLM, deep research modes |
| 3 | Design sketching | Text-to-UI sketch, component visualization | Figma (+Figma Make), Google Stitch, Claude Artifacts |

| 6 | Version control / code storage | Code storage, versioning, sharing, portability | GitHub, GitLab |
| 7 | Hosting and deployment | Publishing a prototype/product online | Vercel, Netlify, Cloudflare Pages |
| 8 | Backend and database | Users, data, files, authentication | Supabase, Firebase, Neon |
| 9 | Skills | Packaging and reusing agent capabilities | Anthropic Skills Marketplace, skills.sh, SkillsMP |
| 10 | Project management | Dividing and tracking work as the team grows | Linear, Notion |
| 11 | Meeting/note-taking tool | Turning conversations into machine-readable text | Granola, Fathom, Fireflies, Otter |
| 12 | Workflow automation / agent building | Chaining tools together, autonomous agents | Zapier, n8n, Make; agent platforms: Lindy, Sintra, Relevance AI |

## Minimum stack for a pre-startup founder

The first five categories (1, 2, 3, 4, 6) are usually enough to build a
working, validated prototype in two days: thinking partner + research +
design sketch + app builder + code storage. Add the rest only once a
genuine need arises (see
`../skills/ai-native-tool-stack-selection/SKILL.md`).

## Three-tier maturity path for agent tools

1. **No-code agent platforms** — for a non-technical founder building
   production agents with a visual interface (e.g. Lindy, Sintra AI,
   Relevance AI, Gumloop).
2. **Open-source runtimes** — for the technically inclined who want an
   autonomous agent on their own machine, with local data (e.g.
   OpenClaw-type local-first runtimes).
3. **Developer frameworks** — once a developer is or will be involved
   (e.g. Claude Agent SDK, OpenAI Agents SDK, LangGraph, CrewAI, Mastra,
   AutoGen, LlamaIndex).

## Reminder

This table goes stale quickly — pricing, free tiers, and features change
weekly in this market. Use it as a category map, not an up-to-date
product comparison.
